# Projeto Bike Sharing

Projeto desenvolvido para a disciplina de **Técnica de Programação — Turma #1715**.

## Objetivo

Realizar o tratamento e a análise de dados utilizando a biblioteca **Pandas** em Python, aplicando os conhecimentos desenvolvidos durante a disciplina.

## Dataset

Foi utilizado o **Bike Sharing Dataset**, disponibilizado pela UCI Machine Learning Repository.

A análise foi realizada com o arquivo `hour.csv`, que contém registros horários de aluguéis de bicicletas referentes aos anos de **2011 e 2012**.

## Etapas do projeto

- Importação e exploração inicial dos dados;
- Descrição das variáveis e dos tipos de dados;
- Verificação de valores nulos e registros duplicados;
- Tratamento e transformação das variáveis;
- Criação de novas colunas para facilitar a interpretação dos dados;
- Elaboração e análise de **11 perguntas** sobre o dataset;
- Utilização de filtros, agrupamentos e transformações com Pandas;
- Cálculo de médias, totais e percentuais;
- Análise dos resultados;
- Visualização gráfica dos resultados por meio de gráficos de linhas e de barras.

## Arquivos do repositório

- `hour.csv` — dataset utilizado nas análises;
- `projeto_cintia.ipynb` — notebook contendo o tratamento dos dados e as 11 análises realizadas;
- `README.md` — apresentação e descrição do projeto.
